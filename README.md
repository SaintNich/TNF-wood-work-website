# TNF Wood Work — Business Website

The official website for TNF Wood Work, a custom woodworking business 
based in Chapin, SC. Built from scratch and deployed to production via 
Netlify.

Live site: [tnfwoodwork.com](https://tnfwoodwork.com)

## Why I Built This

Rather than using a template or website builder, I built this site 
manually to maintain full control over design, performance, and content 
— and to develop real frontend skills in the process. The messaging and 
structure follow the StoryBrand framework, which positions the customer 
as the hero and the business as the guide.

## What the Site Does

The experience is designed around the visitor, not the business. The 
header and hero communicate immediately that they've landed somewhere 
that puts them first — they can move at their own pace or jump straight 
to making contact.

- **Hero section** — clear value proposition with immediate call to 
  action for visitors ready to inquire
- **Gallery** — previous client work with expandable image popouts that 
  tell the story behind each piece
- **Contact form** — simple inquiry form to initiate the conversation
- **Fully responsive** — consistent experience across all viewport sizes
- **Visual consistency** — cohesive design language throughout

## Built With

- HTML, CSS, JavaScript — no frameworks
- Netlify for deployment and hosting
- StoryBrand framework for messaging architecture

## What I Learned

- Structuring a site around a clear customer narrative rather than 
  feature lists
- Responsive design without a framework
- Building interactive elements in vanilla JavaScript — gallery 
  popouts, form handling
- Deploying and maintaining a production site via Netlify
